## 1. 平台与启动

- [x] 1.1 启动时先检查平台，只在 Windows 上继续；其他系统说明不支持并退出，不建清单也不占端口。用测试验证非 Windows 分支在注入平台值后退出且不写清单。
- [x] 1.2 解析启动参数：一个或多个来源文件夹、一个输出文件夹、一个共用阈值。来源文件夹不存在或不是文件夹、输出文件夹不是文件夹、输出文件夹位于任何来源文件夹之内、阈值不是大于等于 0 的整数时，说明原因并退出，不建清单。输出文件夹不存在时创建它。用测试覆盖每种拒绝原因和自动创建。
- [x] 1.3 增加 `.cmd` 启动文件，把全部文件夹和阈值原样传给脚本，路径含空格和中文时仍可用。在 Windows 上手动运行，确认打印全部来源文件夹、输出文件夹、阈值和端口。

## 2. 多文件夹与清单

- [x] 2.1 让一个进程同时枚举全部来源文件夹，共用同一个发现顺序和一个端口。用测试验证两个文件夹交替出现文件时按发现顺序逐部交出，以及一个文件夹为空时另一个仍照常工作。
- [x] 2.2 清单移到输出文件夹，未完成项记下来源文件夹、文件身份和路径。重启后按原顺序继续查。用测试验证跨文件夹顺序、重启续查和来源文件夹记录。
- [x] 2.3 锁覆盖输出文件夹和全部来源文件夹：任何被存活进程占用的目录都会让新脚本退出，退出时释放。用测试验证同一输出文件夹重复启动，以及两个脚本共用一个来源文件夹时后者退出。
- [x] 2.4 把带隐藏或系统属性的条目标为隐藏并跳过，`desktop.ini`、`Thumbs.db`、`$RECYCLE.BIN` 不再进入队列。用测试验证属性判断和点开头名字。
- [x] 2.5 文件身份在没有可用 `ino` 或创建时间时回退到小写完整路径加创建时间，并让旧清单里没有身份标记的记录继续被识别。用测试验证回退比较、同路径不同创建时间视为新文件、旧记录不丢。

## 3. 输出文件夹

- [x] 3.1 达标文件改为移动到输出文件夹：同卷用 rename，跨卷用复制后删除源文件，任一失败都保持文件在原处并记成移动失败。用测试验证同卷移动、跨卷路径和失败时源文件仍在。
- [x] 3.2 目标已存在同名文件时用带序号的新名字保存，保留扩展名，不覆盖已有文件。用测试验证同名两份、三份都能各自保留。
- [x] 3.3 已查完状态改为「已移入输出文件夹」，终端每部剧一行包含来源文件夹、文件名、结果和原因。用测试验证状态名称、终端行内容和同一等待不重复打印。
