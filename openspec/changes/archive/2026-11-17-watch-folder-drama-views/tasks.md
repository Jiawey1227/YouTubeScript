- [x] 1.1 实现文件名到剧名的转换：只去掉最后一个扩展名和首尾空白，空结果记成「名字为空」且不搜索。用单元测试验证 `冰山学姐沦陷了.mp4`、`冰山学姐沦陷了.backup.mp4` 和只剩扩展名的文件。
- [x] 1.2 实现播放量解析和阈值比较：支持纯数字、逗号、「次播放」「次观看」「views」、万/萬、亿/億、k、m，忽略「约」，`1.2万` 等于 12000。取可解析值中的最大值，大于阈值才达标；全部不能解析时单独记成「播放量无法解析」。用单元测试覆盖达标、未达标、部分可解析和全部不能解析。

## 2. 清单与文件队列

- [x] 2.1 实现 `.drama-watch.json` 和独立的锁。清单按发现顺序保存未完成项的 inode、创建时间和路径，并保留已查完状态。同一文件夹的第二个脚本退出；崩溃后下一个脚本能接管。用测试验证重复启动、重启后续查，以及相同 inode 加创建时间不再查。
- [x] 2.2 只接收启动后新出现的这一层普通文件。忽略隐藏文件、子文件夹、符号链接，以及启动时已存在的文件。大小连续 2 秒不变才可交出；未稳定时不插队。稳定前改名用新文件名。用测试验证复制进入、已有文件、隐藏文件和下载改名。

## 3. 搜索结果与废纸篓

- [x] 3.1 按扩展的三种明确结果完成一部剧：未超过阈值、没有匹配、搜索失败都留下且不再重试；超过阈值时移到系统废纸篓并写明最大播放量和阈值。连不上扩展或没有明确结果时保持未完成。用测试验证这几种终态和等待。
- [x] 3.2 废纸篓失败时，文件未变化则下次只重试移动；inode、大小或文件名变了则作废判定并重新等待稳定。搜索开始后改名或变大则丢弃本次结果。终端对同一等待只打一行。用测试验证重试移动、重新搜索和日志不重复。
