# 用户验收清单

以下步骤需要真实 Chrome 和可访问的 YouTube 网络环境。自动化测试不能代替这些步骤。

## 安装与构建

```sh
cd /Users/youzaiking/Documents/Project/youtubescript
nvm use
npm ci
npm run format
npm run check
npm run build
```

预期：全部检查通过，并生成 `dist/manifest.json`、`dist/background.js`、`dist/content.js` 和 `dist/index.html`。

## 加载

1. 打开 `chrome://extensions`。
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择项目中的 `dist/`。
4. 点击扩展按钮，确认中文控制页可以手动输入剧名，并且不要求选择 CSV 文件。

## 输入

1. 不输入剧名就点击“开始搜索”，确认出现输入提示，并且没有打开 YouTube。
2. 输入 21 个非空剧名，确认提示减少到 20 个以内，并且没有开始搜索。
3. 输入不超过 20 个剧名，其中可以夹空行。确认空行被忽略。

## 搜索结果

1. 搜索“冰山学姐沦陷了”，确认专用标签页打开 `https://www.youtube.com/results?search_query=%E5%86%B0%E5%B1%B1%E5%AD%A6%E5%A7%90%E6%B2%A6%E9%99%B7%E4%BA%86`。
2. 对标题含《冰山学姐沦陷了》的普通视频，核对结果中的标题、链接，以及搜索卡片上的播放量和相对时间原文，例如“6659次播放”和“22小时前”。
3. 确认没有因为视频短于或长于 1 小时而排除标题相符的视频，也没有为了补字段而打开视频详情页。
4. 同一剧名有多条相符视频时，确认按搜索页顺序全部出现。
5. 没有相符视频时，确认该剧名保留为“这次搜索没有匹配”，而不是“全站没有该视频”。
6. 让其中一个剧名停在验证码、登录或无法打开的页面，确认该剧名失败并写明原因，其他剧名已得到的结果仍在。

## 文件夹监视

1. 保持扩展已加载，在 Windows 上于项目目录运行 `watch-dramas.cmd --output <输出文件夹> --threshold <阈值> <来源文件夹> [更多来源文件夹…]`。确认终端打印全部来源文件夹、输出文件夹、阈值和端口 `17321`。
2. 在 macOS 或 Linux 上运行同一命令，确认直接提示只支持 Windows 并退出，没有生成清单。
3. 对同一输出文件夹再启动一个脚本，确认第二个脚本退出。让两个脚本使用不同输出文件夹但共用一个来源文件夹，确认后启动的也退出。
4. 打开控制页的「文件夹监视」开关，确认状态显示「已打开」。关掉控制页再打开，确认仍是「已打开」。
5. 把一个视频文件复制进任意一个来源文件夹，确认大约 30 秒内扩展在同一个后台标签里搜索这部剧，并且没有抢走当前页面。
6. 再往另一个来源文件夹复制文件，确认复用了同一个 YouTube 标签，没有新增第二个脚本标签。
7. 播放量超过阈值时，确认文件移动到输出文件夹，终端一行写明来源文件夹、文件名、最大播放量和阈值。
8. 播放量不超过阈值时，确认文件留在原处，终端记录「未超过阈值」。
9. 在输出文件夹预先放一个同名文件，再触发同名剧超阈值，确认新移入的文件用带序号的名字保存，原文件没有被覆盖。
10. 搜索进行中在控制页点击开始或清除，确认被拒绝并显示正在由脚本搜索。
11. 关掉开关，确认扩展不再领取新剧，但已经开始的搜索会收完。
