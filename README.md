# 剧名查播 · YouTube

本地 Chrome 插件：在控制页手动输入最多 20 个剧名，打开对应的 YouTube 搜索页，保留标题包含完整剧名的视频，并记录搜索卡片上的播放量、相对时间和链接。无需 API Key。

**当前状态：功能与自动化检查已完成，最终 Chrome / YouTube 验收由用户执行。** 自动检查记录见 [验证说明](docs/validation.md)，人工验收步骤见 [验收清单](docs/acceptance.md)。真实搜索结果的页面结构、字段准确性与耗时仍需在用户浏览器中确认。

## 环境与安装

- Node.js 22.12 或更新的 Node.js 22 版本，npm。
- Chrome 120 或更新版本，能正常访问 `https://www.youtube.com`。
- 运行任务时保持 Chrome 开启。

安装锁定依赖并运行完整检查：

```sh
cd /Users/youzaiking/Documents/Project/youtubescript
npm ci
npm run format
npm run check
```

日常更新依赖时使用 `npm install` 生成新的 `package-lock.json`；常规安装与复现使用 `npm ci`。依赖均打包到插件中，运行时不从 CDN 加载代码。

开发命令：

```sh
npm run format        # 格式化
npm run format:check  # 检查格式
npm run lint          # 静态规则检查
npm run typecheck     # TypeScript 类型检查
npm test             # 自动测试
npm run build        # 构建到 dist/
npm run check        # 全部检查及构建
```

## 加载插件

1. 构建成功后，在 Chrome 打开 `chrome://extensions`。
2. 开启开发者模式，点击「加载已解压的扩展程序」。
3. 选择本项目的 `dist/` 文件夹（不要选择源码目录）。
4. 点击扩展按钮，打开「剧名查播」控制页。
5. 更新源码并重新构建后，在扩展管理页点击重新加载。

请在真正的扩展页使用，直接双击 `index.html` 不能启动搜索。首版提供本地安装，不涉及商店发布。

## 输入与搜索

在控制页的文本框里每行填写一个剧名，最多 20 个。空行会被忽略，首尾空白会被去掉，重复剧名会分别搜索。超过 20 个或没有有效剧名时不会开始，并给出提示。

点击「开始搜索」后，每个剧名打开：

`https://www.youtube.com/results?search_query=` 加上 URL 编码后的完整剧名。

例如搜索“冰山学姐沦陷了”时，标题中含《冰山学姐沦陷了》的普通视频符合要求。

- 标题需连续包含完整剧名，区分大小写，不自动转换繁简或猜测别名。
- 不按视频时长筛选，也不进入视频详情页。
- 广告、频道、播放列表和 Shorts 专区不作为匹配视频。
- 只读取搜索页初次呈现的普通视频，不翻页，也不为了继续寻找而滚动。
- 同一剧名有多条符合时，按页面顺序全部返回。
- 一个专用标签页按输入顺序搜索。某个剧名无法读取时记为失败并继续后面的剧名，不暂停等待。
- 关闭控制页即结束本次搜索。扩展或浏览器重新启动后，不会恢复旧任务。

## 监视文件夹

控制页顶部的「文件夹监视」开关默认关闭，状态保存在扩展里。打开后，扩展大约每 30 秒向本机脚本要下一部剧，关掉控制页也不停。

文件夹监视脚本只支持 Windows 10 及以上。在 macOS 或 Linux 上启动会直接说明不支持并退出。

先构建，再用 `.cmd` 启动，一次可传多个来源文件夹、一个输出文件夹和一个共用阈值：

```bat
npm run build
watch-dramas.cmd --output "D:\已达标" --threshold 10000 "D:\下载" "E:\新剧"
```

参数顺序不限，路径含空格或中文时加引号。输出文件夹不存在时会自动创建；它不能位于任何来源文件夹之内。阈值必须是大于等于 0 的整数。

脚本只处理启动之后新进入这些文件夹的这一层普通文件，跳过隐藏文件、系统文件、子文件夹和符号链接。剧名取文件名去掉最后一个扩展名后的文字。文件大小连续 2 秒不变后才交给扩展，多个文件夹共用一个发现顺序，一部一部查。

扩展交回的播放量原文由脚本换算：`1.2万` 按 12000、`亿` 按 1 亿、`k` 按 1000、`m` 按 100 万。至少有一条能解析时取最大值，大于阈值才把文件移动到输出文件夹。等于阈值不动，也不会删除文件。输出文件夹里已有同名文件时用 `名字 (2).mp4` 这样的名字另存，不覆盖。

清单是输出文件夹里的 `.drama-watch.json`，并设为隐藏。锁覆盖输出文件夹和每个来源文件夹，所以同一个来源文件夹同时只能被一个脚本监视。查到明确结果的文件会记成「已移入输出文件夹」「未超过阈值」「没有匹配」「搜索失败」「播放量无法解析」或「名字为空」。同一个文件不会重复查。

脚本搜索和手工搜索不能同时进行。脚本搜索时控制页只显示正在由脚本搜索，不会把脚本结果写进结果表。关掉控制页只取消手工搜索。

## 字段含义与限制

返回的是搜索卡片上的原文，例如“6659次播放”和“22小时前”，以及视频标题和链接。播放量不会换算成精确整数，相对时间不会换算成绝对日期。卡片上缺少播放量或相对时间时，该字段显示“不可用”，视频仍会保留。

“这次搜索没有匹配”只表示这次搜索页上没有标题相符的普通视频，不表示全站没有相关视频。搜索结果可能受账号、语言、地区及时间影响。验证码、登录或同意页面会使当前剧名失败；处理页面后可以重新搜索。

搜索剧名会发送给 YouTube，插件不另传第三方服务，也不使用 API Key。

## 故障处理

- **npm ENOTFOUND**：终端无法访问 npm 软件源，检查本机网络后重试；这不等于 YouTube 网页无法访问。
- **后台未响应**：在扩展管理页检查错误并重新加载，重新打开控制页。
- **页面无法识别或字段不可用**：保留失败或“不可用”记录，不要把空着的播放量当成零。
- **搜索标签页被关闭**：当前剧名记为失败，后续剧名会继续使用新标签页。
- **存储失败**：本次搜索停止。重新打开控制页后再搜索。

## 项目结构

- `src/ui.ts`、`src/ui.css`、`src/rows.ts`、`src/gate.ts`：中文控制界面、结果表和按钮状态。
- `src/background.ts`、`src/engine.ts`：专用标签页调度和脚本领取。
- `src/bridge.ts`：扩展与本机脚本的本地端口请求。
- `src/content.ts`、`src/youtube.ts`：搜索页读取与标题、播放量、相对时间解析。
- `src/model.ts`、`src/store.ts`：数据结构，以及运行期间的本机任务存储。
- `src/watch/`：文件夹监视脚本的平台检查、参数、剧名、播放量、多文件夹队列、清单、端口和输出文件夹移动。
- `watch-dramas.cmd`：Windows 启动文件，一次传入来源文件夹、输出文件夹和阈值。
- `tests/`：剧名上限、搜索卡片、调度、旧任务清除、界面结构、权限和文件夹监视测试。
- `manifest.json`：扩展权限与入口声明。
- `scripts/build.mjs`：构建页面、独立后台/内容脚本和 `dist/watch-dramas.js`，并复制 manifest。
- `docs/`：验证记录和验收步骤。
- `openspec/changes/watch-folder-drama-views/`：文件夹监视的提案、规格、设计与任务。
